# Review Checklist: UI Cohesion & Dynamic Polish

> Designation **024A**. This checklist is intentionally independent from the
> **024B / roadmap phase 25** command-center release checklist.

- [ ] Popup and manager use a unified visual system
- [ ] Spacing, radii, and shadows are consistent
- [ ] Selection, hover, and focus states are clear
- [ ] Empty states feel deliberate and readable
- [ ] Manager layout remains balanced across breakpoints
- [ ] Motion is subtle and consistent
- [ ] Keyboard behavior is unchanged
- [ ] `just verify` passes
- [ ] Screenshots updated where needed
