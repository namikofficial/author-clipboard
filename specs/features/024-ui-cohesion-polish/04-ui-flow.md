# UI Flow: UI Cohesion & Dynamic Polish

## Popup

1. User opens popup.
2. The surface appears with a clear search-first hierarchy.
3. Search, filter chips, and list rows share a consistent density.
4. Selection changes animate subtly.
5. Empty states show clear messaging and a deliberate icon.

## Manager

1. User opens manager.
2. Sidebar, list, and preview establish the shell structure immediately.
3. Wide layouts keep the preview anchored with stable spacing.
4. Narrow layouts collapse without making the UI feel cramped.
5. Toasts and state chips appear in a consistent location.

## State Feedback

1. Hover or focus changes are visible but restrained.
2. Redacted content has a clear protected state.
3. Reveal/countdown feedback is readable without dominating the screen.
4. Light and dark themes remain visually aligned.
