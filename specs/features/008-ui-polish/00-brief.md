# Feature Brief: UI Polish & Native Icons

> Replace emoji buttons with COSMIC symbolic icons, add content type icons, improve empty states and status indicators.

---

## Problem Statement

The UI uses emoji for buttons and lacks visual polish. Users need clear visual feedback and proper COSMIC-native theming.

## Proposed Solution

Replace all emoji buttons with COSMIC symbolic icons, add content type indicators, improve empty states, and add daemon status indicator.

## Goals

- Symbolic icons for pin, delete, clear, incognito, settings
- Content type icons (text, image, HTML, document)
- Improved empty state with centered icon and descriptive text
- Daemon running status indicator in Settings tab
