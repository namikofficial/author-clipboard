# Review Checklist: Rich Content Completion

- [ ] Image filenames resolve under the configured data directory.
- [ ] Failed image loads cannot retain a stale preview.
- [ ] HTML compact previews use plain text, not MIME labels.
- [ ] Default HTML preview does not execute active content.
- [ ] URI-list comments are ignored and names are decoded.
- [ ] File rows show existence, MIME, and size information.
- [ ] Original MIME types remain intact for copy/restore.
- [ ] Sensitive rich content remains redacted by default.
- [ ] Targeted tests pass.
- [ ] Formatting and lint checks pass.
